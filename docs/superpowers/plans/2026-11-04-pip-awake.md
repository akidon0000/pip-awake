# pip-awake Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 社有 iPhone で、PiP に時計を流し続けて画面を点けたままにする iOS アプリを作る。給電中だけ動く。

**Architecture:** `AVSampleBufferDisplayLayer` に時計のフレームを毎秒 enqueue し、`AVPictureInPictureController` の sample buffer 用 content source で PiP に出す。状態は `AwakeSession` が持つ。電源・PiP・供給・オーディオはプロトコル越しに渡すので、偽物を差し込んでテストできる。

**Tech Stack:** Swift 6、SwiftUI、Observation、AVKit / AVFoundation、Swift Testing、XcodeGen、SwiftLint・swift-format（ios-project-template の設定を流用）

**Spec:** [2026-11-04-pip-awake-design.md](../specs/2026-11-04-pip-awake-design.md)

**Milestones:** Task 1〜7 で最小構成を作り、社有端末で成功条件 1・2 を確かめる（Task 7 で止まる）。確かめられたら Task 8〜11 で残りを作る。

## Global Constraints

- 最低 OS は iOS 17.0。Swift 6（strict concurrency）、SwiftUI、Observation
- Bundle ID は `dev.akidon.pipawake`、テストは `dev.akidon.pipawake.tests`。Team は `XSC9AJPSP3`、自動署名
- 表示名は `Awake`
- Background Modes は `audio` のみ（PiP に必要）
- オーディオセッションは `.playback` + `.mixWithOthers`。ほかのアプリの音を止めない
- 映像は 640×50、BGRA、1 fps。フレームの duration は 1 秒（改訂 1 で 640×360 から、改訂 2 で 640×180 から変更）
- 配布は Xcode から社有端末へ直接インストールのみ。TestFlight・App Store・CI は作らない
- 設定画面、無線デバッグ対応、自動再開は作らない
- `.swiftlint.yml` と `.swift-format` は ios-project-template のものをそのまま使う。`swiftlint lint --strict` と `swift-format lint` が通ること
- 画面の文言は日本語で、spec の文言と一致させる
- ファイルを追加・削除したら、テストの前に `xcodegen generate` を実行する
- コミットメッセージ末尾には、その時点のシステム指示どおりの Co-Authored-By 行を付ける

## 改訂 1（2026-11-05、ユーザー指示）

PiP 窓の表示を変更した。Task 1〜7 は改訂前の内容で実装・完了済みで、台帳に記録している。以降のタスクはこの改訂を前提にする。

- PiP 窓は 640×180（横長）。上段に経過時間 `H:MM:SS`、下段に給電状況（`給電中` / `未給電`）。現在時刻は表示しない
- `ClockText`（Task 2）は削除した。経過時間は `ElapsedFormatter`、給電状況は描画部品が直接扱う
- `ClockFrame` から `now` を削除し、`elapsed` と `isPluggedIn` だけにした（Task 3・4・5 は改訂後の形で実装済み）
- 画面の表示比率は 640:180。Task 10 の `ContentView` もこの比率を使う
- 給電が外れたら PiP を即座に閉じて供給を止める（Task 9 の状態遷移どおり）。電源の変化通知で検知し、通知が届かない場合は供給中の毎秒の確認で検知する（最大約 1 秒）

## 改訂 2（2026-11-04、ユーザー指示）

PiP 窓の高さを縮め、経過時間と給電状況を横一列にした。

- 映像は 640×50。左に経過時間 `H:MM:SS`、右に給電状況（`給電中` / `未給電`）を `ClockFrameView`（SwiftUI の HStack）で並べる
- `ClockFrameRenderer` は `ClockFrameView` を `ImageRenderer`（scale 1）で画像にし、CVPixelBuffer に描く。`ClockFrameRenderer` と `ClockFrameView` は `@MainActor`
- 画面の表示比率は 640:50。`ContentView` の `aspectRatio` もこの比率にし、表示の幅は画面幅に合わせて決まる（幅の固定値は持たない）
- 実機の PiP 窓の大きさと見え方は未確認

## Review Focus

実装者が見落としやすく、使う人が最も困りそうな 5 点。各行の後ろのテストが、担当タスクで挙動を固定する。

1. 給電が抜けて戻った後は自動で再開せず、押し直しが必要 → `canRestartAfterReplugging`（Task 9）
2. バッテリー状態が `.unknown` のときは未給電扱いになり、開始できない → `mapsBatteryStateOnDevice`（Task 8）
3. 動作中にもう一度開始を押しても二重に起動しない → `startIsIgnoredWhileActive`（Task 9）
4. 1 時間を超える経過時間や、時計が巻き戻ったときの負の経過時間でも表示が崩れない → `formatsAsHoursMinutesSeconds`（Task 2）
5. PiP が使えない端末では、理由を画面に出す（無言で止まらない） → `unsupportedWinsOverState`（Task 10）

```swift
import Foundation

enum ElapsedFormatter {
    static func string(from seconds: TimeInterval) -> String {
        let total = max(0, Int(seconds))
        return String(format: "%d:%02d:%02d", total / 3600, total % 3600 / 60, total % 60)
    }
}
```

```swift
import Foundation

enum ClockText {
    static func time(_ date: Date, calendar: Calendar = .current) -> String {
        let parts = calendar.dateComponents([.hour, .minute, .second], from: date)
        let hour = parts.hour ?? 0
        let minute = parts.minute ?? 0
        let second = parts.second ?? 0
        return String(format: "%02d:%02d:%02d", hour, minute, second)
    }

    static func subtitle(elapsed: TimeInterval, isPluggedIn: Bool) -> String {
        let power = isPluggedIn ? "給電中" : "未給電"
        return "経過 \(ElapsedFormatter.string(from: elapsed)) ・ \(power)"
    }
}
```

`PipAwake/ClockFrameRenderer.swift`:

```swift
import CoreVideo
import UIKit

struct ClockFrame: Equatable {
    var now: Date
    var elapsed: TimeInterval
    var isPluggedIn: Bool
}

struct ClockFrameRenderer {
    static let width = 640
    static let height = 360

    var calendar: Calendar = .current

    func render(_ frame: ClockFrame) -> CVPixelBuffer? {
        guard let buffer = makePixelBuffer() else {
            return nil
        }
        CVPixelBufferLockBaseAddress(buffer, [])
        defer { CVPixelBufferUnlockBaseAddress(buffer, []) }
        guard
            let context = CGContext(
                data: CVPixelBufferGetBaseAddress(buffer),
                width: Self.width,
                height: Self.height,
                bitsPerComponent: 8,
                bytesPerRow: CVPixelBufferGetBytesPerRow(buffer),
                space: CGColorSpaceCreateDeviceRGB(),
                bitmapInfo: CGImageAlphaInfo.premultipliedFirst.rawValue
                    | CGBitmapInfo.byteOrder32Little.rawValue
            )
        else {
            return nil
        }
        draw(frame, in: context)
        return buffer
    }

    private func makePixelBuffer() -> CVPixelBuffer? {
        let attributes: [CFString: Any] = [
            kCVPixelBufferCGImageCompatibilityKey: true,
            kCVPixelBufferCGBitmapContextCompatibilityKey: true,
            kCVPixelBufferIOSurfacePropertiesKey: [String: Any]()
        ]
        var buffer: CVPixelBuffer?
        let status = CVPixelBufferCreate(
            kCFAllocatorDefault,
            Self.width,
            Self.height,
            kCVPixelFormatType_32BGRA,
            attributes as CFDictionary,
            &buffer
        )
        guard status == kCVReturnSuccess else {
            return nil
        }
        return buffer
    }

    private func draw(_ frame: ClockFrame, in context: CGContext) {
        let width = CGFloat(Self.width)
        context.setFillColor(UIColor.black.cgColor)
        context.fill(CGRect(x: 0, y: 0, width: width, height: CGFloat(Self.height)))
        // UIKit の文字描画は左上原点なので、ビットマップの座標系を上下反転してから描く
        context.translateBy(x: 0, y: CGFloat(Self.height))
        context.scaleBy(x: 1, y: -1)
        UIGraphicsPushContext(context)
        defer { UIGraphicsPopContext() }
        drawCentered(
            ClockText.time(frame.now, calendar: calendar),
            font: .monospacedDigitSystemFont(ofSize: 120, weight: .semibold),
            color: .white,
            centerY: 160,
            width: width
        )
        drawCentered(
            ClockText.subtitle(elapsed: frame.elapsed, isPluggedIn: frame.isPluggedIn),
            font: .monospacedDigitSystemFont(ofSize: 30, weight: .regular),
            color: .lightGray,
            centerY: 290,
            width: width
        )
    }

    private func drawCentered(
        _ text: String, font: UIFont, color: UIColor, centerY: CGFloat, width: CGFloat
    ) {
        let attributed = NSAttributedString(
            string: text,
            attributes: [.font: font, .foregroundColor: color]
        )
        let size = attributed.size()
        attributed.draw(at: CGPoint(x: (width - size.width) / 2, y: centerY - size.height / 2))
    }
}
```

```swift
import CoreMedia
import CoreVideo

enum SampleBufferFactory {
    static let frameDuration = CMTime(value: 1, timescale: 1)

    static func make(from pixelBuffer: CVPixelBuffer, presentationTime: CMTime) -> CMSampleBuffer? {
        var formatDescription: CMVideoFormatDescription?
        let formatStatus = CMVideoFormatDescriptionCreateForImageBuffer(
            allocator: kCFAllocatorDefault,
            imageBuffer: pixelBuffer,
            formatDescriptionOut: &formatDescription
        )
        guard formatStatus == noErr, let formatDescription else {
            return nil
        }
        var timing = CMSampleTimingInfo(
            duration: frameDuration,
            presentationTimeStamp: presentationTime,
            decodeTimeStamp: .invalid
        )
        var sampleBuffer: CMSampleBuffer?
        let status = CMSampleBufferCreateReadyWithImageBuffer(
            allocator: kCFAllocatorDefault,
            imageBuffer: pixelBuffer,
            formatDescription: formatDescription,
            sampleTiming: &timing,
            sampleBufferOut: &sampleBuffer
        )
        guard status == noErr else {
            return nil
        }
        return sampleBuffer
    }
}
```

```swift
import AVFoundation

@MainActor
protocol FrameFeeding: AnyObject {
    func start(startedAt: Date)
    func pause()
    func resume()
    func stop()
}

@MainActor
final class ClockSampleBufferFeeder: FrameFeeding {
    let displayLayer = AVSampleBufferDisplayLayer()
    /// 毎フレーム呼ぶ。給電状態の表示と、通知が届かない場合のポーリングを兼ねる
    var isPluggedIn: () -> Bool = { true }

    private let renderer = ClockFrameRenderer()
    private let timebase: CMTimebase
    private var timer: Timer?
    private var startedAt = Date()
    private var isRunning = false

    init() {
        do {
            timebase = try CMTimebase(sourceClock: .hostTimeClock)
        } catch {
            fatalError("CMTimebase を作れませんでした: \(error)")
        }
        displayLayer.controlTimebase = timebase
        displayLayer.videoGravity = .resizeAspect
        displayLayer.preventsDisplaySleepDuringVideoPlayback = false
    }

    func start(startedAt: Date) {
        self.startedAt = startedAt
        try? timebase.setTime(.zero)
        play()
    }

    func pause() {
        isRunning = false
        invalidateTimer()
        try? timebase.setRate(0)
        displayLayer.preventsDisplaySleepDuringVideoPlayback = false
    }

    func resume() {
        play()
    }

    func stop() {
        pause()
        let output = displayLayer.sampleBufferRenderer
        output.flush(removingDisplayedImage: true, completionHandler: nil)
    }

    private func play() {
        isRunning = true
        try? timebase.setRate(1)
        displayLayer.preventsDisplaySleepDuringVideoPlayback = true
        enqueueFrame()
        invalidateTimer()
        let timer = Timer(timeInterval: 1, repeats: true) { [weak self] _ in
            MainActor.assumeIsolated {
                self?.enqueueFrame()
            }
        }
        RunLoop.main.add(timer, forMode: .common)
        self.timer = timer
    }

    private func invalidateTimer() {
        timer?.invalidate()
        timer = nil
    }

    private func enqueueFrame() {
        let now = Date()
        let isPluggedIn = isPluggedIn()
        // isPluggedIn() の中で給電切れを検知して stop() が呼ばれることがある
        guard isRunning else {
            return
        }
        let output = displayLayer.sampleBufferRenderer
        if output.status == .failed || output.requiresFlushToResumeDecoding {
            output.flush()
        }
        let frame = ClockFrame(
            now: now,
            elapsed: now.timeIntervalSince(startedAt),
            isPluggedIn: isPluggedIn
        )
        let time = timebase.time
        guard
            let pixelBuffer = renderer.render(frame),
            let sample = SampleBufferFactory.make(from: pixelBuffer, presentationTime: time)
        else {
            return
        }
        output.enqueue(sample)
    }
}
```

```swift
import AVKit

enum PiPEvent: Equatable {
    case didStart
    case failedToStart(String)
    case didStop(restored: Bool)
    case playingChanged(Bool)
}

@MainActor
protocol PiPControlling: AnyObject {
    var isSupported: Bool { get }
    var onEvent: ((PiPEvent) -> Void)? { get set }
    func start()
    func stop()
}

@MainActor
final class PiPController: NSObject, PiPControlling, AVPictureInPictureControllerDelegate {
    var onEvent: ((PiPEvent) -> Void)?
    var isSupported: Bool { AVPictureInPictureController.isPictureInPictureSupported() }

    private let controller: AVPictureInPictureController
    private let playbackDelegate: SampleBufferPlaybackDelegate
    private var startAttempt: Task<Void, Never>?
    private var restoreRequested = false

    init(displayLayer: AVSampleBufferDisplayLayer) {
        let playbackDelegate = SampleBufferPlaybackDelegate()
        let contentSource = AVPictureInPictureController.ContentSource(
            sampleBufferDisplayLayer: displayLayer,
            playbackDelegate: playbackDelegate
        )
        self.playbackDelegate = playbackDelegate
        controller = AVPictureInPictureController(contentSource: contentSource)
        super.init()
        controller.delegate = self
        controller.requiresLinearPlayback = true
        controller.canStartPictureInPictureAutomaticallyFromInline = false
        playbackDelegate.setOnSetPlaying { [weak self] playing in
            Task { @MainActor in
                self?.onEvent?(.playingChanged(playing))
            }
        }
    }

    /// delegate はメインスレッドから呼ばれる想定だが、保証はないので外れたときだけ hop する
    nonisolated private static func onMain(_ body: @escaping @MainActor @Sendable () -> Void) {
        if Thread.isMainThread {
            MainActor.assumeIsolated {
                body()
            }
        } else {
            Task { @MainActor in
                body()
            }
        }
    }

    func start() {
        playbackDelegate.isPaused = false
        controller.invalidatePlaybackState()
        controller.canStartPictureInPictureAutomaticallyFromInline = true
        startAttempt?.cancel()
        if controller.isPictureInPicturePossible {
            controller.startPictureInPicture()
            return
        }
        // レイヤーがウィンドウに載った直後は isPictureInPicturePossible が false のことがあるので待つ
        startAttempt = Task { [weak self] in
            for _ in 0..<30 {
                try? await Task.sleep(for: .milliseconds(100))
                guard let self, !Task.isCancelled else {
                    return
                }
                if controller.isPictureInPicturePossible {
                    controller.startPictureInPicture()
                    return
                }
            }
            self?.onEvent?(.failedToStart("PiP の準備ができませんでした"))
        }
    }

    func stop() {
        startAttempt?.cancel()
        startAttempt = nil
        controller.canStartPictureInPictureAutomaticallyFromInline = false
        if controller.isPictureInPictureActive {
            controller.stopPictureInPicture()
        }
    }

    nonisolated func pictureInPictureControllerDidStartPictureInPicture(
        _ pictureInPictureController: AVPictureInPictureController
    ) {
        Self.onMain { [weak self] in
            self?.onEvent?(.didStart)
        }
    }

    nonisolated func pictureInPictureController(
        _ pictureInPictureController: AVPictureInPictureController,
        failedToStartPictureInPictureWithError error: any Error
    ) {
        let message = error.localizedDescription
        Self.onMain { [weak self] in
            self?.onEvent?(.failedToStart(message))
        }
    }

    nonisolated func pictureInPictureController(
        _ pictureInPictureController: AVPictureInPictureController,
        restoreUserInterfaceForPictureInPictureStopWithCompletionHandler completionHandler:
            @escaping (Bool) -> Void
    ) {
        Self.onMain { [weak self] in
            self?.restoreRequested = true
        }
        completionHandler(true)
    }

    nonisolated func pictureInPictureControllerDidStopPictureInPicture(
        _ pictureInPictureController: AVPictureInPictureController
    ) {
        Self.onMain { [weak self] in
            guard let self else {
                return
            }
            let restored = restoreRequested
            restoreRequested = false
            onEvent?(.didStop(restored: restored))
        }
    }
}
```

```swift
import UIKit

@MainActor
protocol PowerMonitoring: AnyObject {
    var isPluggedIn: Bool { get }
    var onChange: ((Bool) -> Void)? { get set }
}

@MainActor
final class PowerMonitor: PowerMonitoring {
    #if targetEnvironment(simulator)
        static let isSimulator = true
    #else
        static let isSimulator = false
    #endif

    var onChange: ((Bool) -> Void)?
    private(set) var isPluggedIn: Bool

    private let device: UIDevice
    private var observer: (any NSObjectProtocol)?

    init(device: UIDevice = .current) {
        self.device = device
        device.isBatteryMonitoringEnabled = true
        isPluggedIn = Self.isPluggedIn(device.batteryState, isSimulator: Self.isSimulator)
        observer = NotificationCenter.default.addObserver(
            forName: UIDevice.batteryStateDidChangeNotification,
            object: device,
            queue: .main
        ) { [weak self] _ in
            MainActor.assumeIsolated {
                _ = self?.refresh()
            }
        }
    }

    static func isPluggedIn(_ state: UIDevice.BatteryState, isSimulator: Bool) -> Bool {
        if isSimulator {
            return true
        }
        switch state {
        case .charging, .full:
            return true

        case .unplugged, .unknown:
            return false

        @unknown default:
            return false
        }
    }

    /// 給電状態を読み直し、変わっていれば onChange を呼ぶ。通知が届かない場合に備えて毎フレーム呼ばれる
    @discardableResult
    func refresh() -> Bool {
        let latest = Self.isPluggedIn(device.batteryState, isSimulator: Self.isSimulator)
        if latest != isPluggedIn {
            isPluggedIn = latest
            onChange?(latest)
        }
        return latest
    }
}
```

```swift
import Foundation
import Observation

enum AwakeState: Equatable {
    case idle
    case starting
    case running
    case paused
    case stoppedByUnplug
    case failed(String)
}

@MainActor
@Observable
final class AwakeSession {
    private(set) var state = AwakeState.idle
    private(set) var isPluggedIn: Bool
    private(set) var startedAt: Date?

    var isPictureInPictureSupported: Bool { pictureInPicture.isSupported }
    var isActive: Bool { [.starting, .running, .paused].contains(state) }
    var canStart: Bool { isPluggedIn && isPictureInPictureSupported && !isActive }

    private let power: any PowerMonitoring
    private let feeder: any FrameFeeding
    private let pictureInPicture: any PiPControlling
    private let audioSession: any AudioSessionControlling
    private let setIdleTimerDisabled: (Bool) -> Void
    private let now: () -> Date

    init(
        power: any PowerMonitoring,
        feeder: any FrameFeeding,
        pictureInPicture: any PiPControlling,
        audioSession: any AudioSessionControlling,
        setIdleTimerDisabled: @escaping (Bool) -> Void,
        now: @escaping () -> Date = Date.init
    ) {
        self.power = power
        self.feeder = feeder
        self.pictureInPicture = pictureInPicture
        self.audioSession = audioSession
        self.setIdleTimerDisabled = setIdleTimerDisabled
        self.now = now
        isPluggedIn = power.isPluggedIn
        power.onChange = { [weak self] isPluggedIn in
            self?.powerChanged(isPluggedIn)
        }
        pictureInPicture.onEvent = { [weak self] event in
            self?.handle(event)
        }
    }

    func start() {
        guard canStart else {
            return
        }
        do {
            try audioSession.activate()
        } catch {
            state = .failed(error.localizedDescription)
            return
        }
        let startedAt = now()
        self.startedAt = startedAt
        state = .starting
        setIdleTimerDisabled(true)
        feeder.start(startedAt: startedAt)
        pictureInPicture.start()
    }

    func stop() {
        guard isActive else {
            return
        }
        tearDown(to: .idle)
    }

    private func powerChanged(_ isPluggedIn: Bool) {
        self.isPluggedIn = isPluggedIn
        if !isPluggedIn && isActive {
            tearDown(to: .stoppedByUnplug)
        }
    }

    private func handle(_ event: PiPEvent) {
        switch event {
        case .didStart:
            if state == .starting {
                state = .running
            }

        case .failedToStart(let reason):
            if state == .starting {
                tearDown(to: .failed(reason))
            }

        case .didStop(let restored):
            // 「アプリに戻る」で閉じたときは前面でインライン表示を続ける
            if !restored && isActive {
                tearDown(to: .idle)
            }

        case .playingChanged(let isPlaying):
            setPlaying(isPlaying)
        }
    }

    private func setPlaying(_ isPlaying: Bool) {
        if state == .running && !isPlaying {
            state = .paused
            feeder.pause()
            setIdleTimerDisabled(false)
        } else if state == .paused && isPlaying {
            state = .running
            feeder.resume()
            setIdleTimerDisabled(true)
        }
    }

    private func tearDown(to newState: AwakeState) {
        state = newState
        startedAt = nil
        feeder.stop()
        pictureInPicture.stop()
        audioSession.deactivate()
        setIdleTimerDisabled(false)
    }
}
```

```swift
enum StatusText {
    static func message(for state: AwakeState, isPluggedIn: Bool, isSupported: Bool) -> String {
        guard isSupported else {
            return "この端末は PiP に対応していません"
        }
        switch state {
        case .idle:
            return isPluggedIn ? "開始すると PiP で経過時間を流し、画面を点けたままにします" : "ケーブルをつないでください"

        case .starting, .running:
            return "画面を点けたままにしています"

        case .paused:
            return "一時停止中。この間は画面が消えます"

        case .stoppedByUnplug:
            return "ケーブルが外れたので止めました"

        case .failed(let reason):
            return "PiP を開始できませんでした: \(reason)"
        }
    }
}
```
